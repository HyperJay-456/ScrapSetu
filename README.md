# KabadiConnect

A mobile-first hackathon MVP that helps informal e-waste collectors discover fair local prices, create traceable material lots, and connect with verified recyclers.

## Run it

Open \`index.html\` in any modern browser. No build step or dependency installation is required.

## Demo flow

1. Start on the Marathi collector home screen.
2. Tap **नवीन माल जोडा** (or the center scan button), choose a material and weight, and create a lot.
3. The app calculates an estimated local value and saves the lot in the earnings ledger.
4. Open **रिसायकलर** to demonstrate verified recycler matching and pickup availability.
5. Toggle **Online** in the header to demonstrate the offline-first state; created lots are retained in browser local storage.
6. Use the speaker buttons on Prices and Safety for the voice-assistance demo.

## Included in this prototype

- Marathi-first low-literacy collector experience
- One-tap Marathi, Hindi, and English interface switching
- Spoken price guidance for every material in the price board and lot picker
- Live-style price board with basic market trends
- Lot creation, approximate valuation, and persisted transaction data
- Verified recycler list ranked by distance/rate/pickup availability
- Earnings ledger with pending payment state
- Safety guidance for batteries, CRTs, and cable burning
- Offline state indicator and browser-local data persistence

The recycler names, authorization badges, prices, and locations are demonstration data. Replace these with field-validated data and a verified recycler registry before any production use.
